# LIFE STORY
나의 인생을 담은 모바일 횡스크롤 게임

[게임 실행하기 — Galaxy Chrome / 모바일·PC](https://hayoo74-ops.github.io/life-story-game/)

갤럭시 Chrome에서 링크를 열고 **새 게임** 또는 **이어하기**를 선택하세요. 첫 리소스 캐싱 뒤 오프라인 재실행을 지원합니다. 홈 화면에 추가는 브라우저 메뉴에서 선택할 수 있습니다.

**챕터 1 v1.3 — 탐색과 기억의 흔적.** 종이놀이·액션가면 자세·세 문제 공부, 사물별 동작, 후속 대화와 사진첩의 선택 흔적을 추가했습니다. 기존 서사·멀티터치·오프라인을 유지하며 대화 기록·접근성·음량·JSON 보관 기능을 통합했습니다. **챕터 2–8은 기획 단계**입니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
git clone https://github.com/hayoo74-ops/life-story-game.git
cd life-story-game
npm ci
npm run dev
```

터미널에 출력된 주소를 엽니다. 기본은 `http://localhost:5173/life-story-game/`이며 포트 충돌 시 달라집니다. HTML 파일을 직접 열지 마세요.

```sh
npm test
npm run build
npm run preview
```

HTML5/CSS3/JavaScript, Phaser 3, Vite, Web Audio, LocalStorage, PWA를 사용합니다. 빌드 결과는 `dist/`입니다.

## 플레이

← → / A·D로 이동, ↟ / Space / W로 점프, ✦ / E로 대화·조사합니다. 이동과 점프를 함께 누를 수 있습니다. 대화창 터치·Enter·E로 다음 대사, 선택지는 직접 터치하거나 Tab·Enter·숫자로 고릅니다. 글자가 출력 중이면 첫 입력은 전체 표시, 다음 입력은 다음 대사입니다. Ⅱ / ☰ / Esc는 메뉴입니다.

하단 목표에 따라 가족에게 말을 걸고 사물을 살펴보세요. 주요 대화를 마치지 않고 사물만 조사해서 장면을 넘길 수 없습니다. 처음 보는 컷신은 대사·행동을 끝까지 진행하고, 다시 보는 v1.2 컷신은 ‘본 장면 건너뛰기’로 넘길 수 있습니다. 개정 전의 짧은 컷신을 본 이력과 새로운 대본을 본 이력은 구분합니다.

골목·놀이터·문구점·학교 앞은 선택 탐험입니다. 길 끝 표지판에서 ✦로 이동하며 학교 앞에서 집으로 돌아갈 수 있습니다. 모든 선택 기억을 모을 필요는 없습니다. 챕터 완료 후 메뉴의 열두 장면을 눌러 수집을 보존한 채 재방문할 수 있습니다.

## 새 놀이와 설정

형제 막간에서 비행기/배를 세 번 접고 힘을 골라 날리거나 밀어 보세요. 다시 시도하면 최고 거리를 기록합니다. 아버지 앞에서는 액션가면 자세를 고르고, 공부방에서는 세 문제를 천천히 풉니다. 오답이어도 다음 이야기로 갑니다. TV·서랍·장난감·책·사진·침대에는 각각 다른 동작이 있습니다.

대화창의 ‘기록’으로 이전 대화를 읽고 Ⅱ로 쉽니다. 설정에서 글자 크기 3단계, 출력 속도, 자동 진행, 고대비, 자막 배경, 움직임 줄이기, 전체/음악/효과음 음량을 조절합니다. 기본은 음소거입니다. 조작키 재설정은 미구현입니다.

## 이야기는 어떻게 바뀌었나

핵심 순서는 유지합니다.

**학장동에서 부모님과 생활 → 종이가면을 쓰고 함께 웃은 기억 → 약 1~2년 뒤 방문 파손 직접 목격 → 얼마 후 부모님 이혼 → 아버지와 약 1~2년 → 부산 남구 대연동 조부모님 댁 → 공부에 엄격했던 생활.**

- 어머니와 인사하고 사진을 함께 봅니다. 종이를 발견하고 가면을 준비합니다.
- 아버지와의 일상 대화, 선택에 대한 반응, 반복 방문 시 다른 말을 추가했습니다.
- **액션가면 22개 대사·행동**: TV를 보는 부모님, 가면 착용과 영웅 포즈, 두 실제 대사, 아버지의 장난과 웃음, 어머니와 재원의 반응을 결합했습니다. 장난은 화면 밖으로 처리하며 옷·신체 노출을 만들지 않습니다.
- 방문 파손은 7개 비트로 직접 목격한 사건을 유지하며 짧은 독백·문 파손·충격음·정적을 사용합니다. 원인이나 부모의 미확인 심각한 발언, 추가 폭력은 만들지 않습니다.
- 아버지와 단둘이 살던 시기에는 식사 준비·수저 놓기·외출 준비 같은 작은 대화가 있습니다. 중대한 사건이나 관계 전체의 성격을 새로 확정하지 않습니다.
- 조부모님은 문제집·연필·풀이를 두고 대화하며 공부 전후와 재방문에 따라 말이 달라집니다. 오답·그림부터 보기·정답 모두 진행합니다. 특정 조부모를 체벌 행위자로 지정하지 않습니다.

## 형과 종이 한 장

형을 가족관계, 전용 픽셀 캐릭터, 대화·선택·사물·9비트 컷신, 17번째 기억에 추가했습니다. 형제는 비행기/배를 고르고 종이 양 끝을 잡아 함께 접습니다. 반복 대화와 후반부 대사가 달라집니다.

형의 동거 시기·나이 차이·성격·두 핵심 사건의 목격 여부는 미확인입니다. 따라서 **형은 부모님 거실·방문 파손·아버지 단독 동거 맵에 배치하지 않습니다.** 접힌 종이로 들어가는 별도의 **‘막간 · 종이 한 장’**은 날짜·거주지를 지정하지 않는 극적 재구성입니다. 형이 그때 같은 집에 살았다는 주장이 아닙니다. 장면을 마치면 원래 위치로 돌아옵니다. 막간 안에서 종료해도 형제 선택과 돌아갈 위치를 저장합니다.

## 출처와 대사의 관리

일반 대화·회상·기억 획득 화면에는 사실 확인 문구나 출처 배지를 반복 표시하지 않습니다. 등장인물의 말, 독백, 짧은 장면 묘사만 보여 줍니다. **앨범의 ‘출처와 제작 메모’ 및 메뉴의 ‘가족과 이야기의 출처’에서만** 구분을 읽습니다.

각 대사와 사건은 내부적으로 다음 메타데이터를 가집니다.

| sourceType | 의미 |
|---|---|
| `real_memory` | 제공된 핵심 사건·두 직접 대사 |
| `fictional_dialogue` | 자연스럽게 창작한 일상 대사와 반응 |
| `dramatic_reconstruction` | 공간·동작·카메라·문학적 독백·형제 막간 |

실제 기억의 직접 대사는 **“우하하하! 난 액션가면!”**, **“액션가면은 빤쓰만 입고 있는다.”**입니다. 나머지 일상 대사는 등장인물 관계와 상황을 바탕으로 창작했습니다. 사건 원인·법적 절차·새로운 심각한 폭언/폭력·체벌 횟수/상해를 만들어 사실로 확정하지 않습니다. 유년기 나이·정확한 연도·주거지 주소도 추가하지 않았습니다. 학장동 지역 표기는 제공된 최신 기록을 따릅니다.

## 저장과 호환

현재 스키마는 **v4**이며 기본 키는 `life-story:save`입니다.

- v2/v3는 **장면·위치·기억·퀘스트·설정·선택을 보존**해 업그레이드합니다. 새 대화 방문 횟수와 개정 컷신 관람 이력을 추가합니다.
- v2/v3 원본은 각각 `life-story:save:v2-backup`, `life-story:save:v3-backup`에 보관합니다. 백업이 실패하면 기존 저장을 덮어쓰지 않습니다.
- v1은 이전의 사실관계 변경에 따라 원본과 수집 ID를 백업/legacyArchive에 보존하고 새 프롤로그에서 시작하는 기존 정책을 유지합니다.
- 형제 막간의 복귀점·선택·대화 이력도 저장합니다. 컷신을 중단하면 잠긴 화면 대신 사건의 시작 경계에서 다시 진행합니다.
- 상위 버전·손상 데이터는 오류를 알립니다. 저장이 차단돼도 게임은 실행되지만 진행 보존을 보장할 수 없습니다.

메뉴의 ‘저장 파일 내보내기 / 가져오기’로 진행을 JSON 파일에 보관할 수 있습니다. 가져오기는 검증·미리보기 뒤 직접 복구를 눌러 적용하며, 직전 진행은 `life-story:save:before-import`에 보관합니다. 손상·상위 버전·쓰기 실패는 기존 진행을 유지합니다.

저장은 이 기기·브라우저·사이트 주소별 LocalStorage입니다. 클라우드 동기화는 없으며 브라우저 데이터를 지우면 사라집니다.

## 데이터 편집

- `src/data/dialogue.js`: 자연스러운 가족·배경 NPC 대사, 반복/상황별 분기, 사물 독백, 22/7/9비트 대본.
- `src/data/family.js`: 가족 6명의 관계·미확인 항목, 주요 대화 진행 조건과 목표.
- `src/data/chapter-one.js`: 12개 주요 장면, 별도 형제 막간, 장소·사물·기억·사건 메타데이터.
- `src/main.js`: 대화 진행·선택·퀘스트 조건·회상·재관람 생략·앨범/기록 메뉴.
- `src/game.js`, `src/art.js`: 이동·충돌·카메라·비트별 연기와 오리지널 픽셀아트.
- `src/save.js`: v1/v2/v3→v4 호환, 대화/컷신/막간 저장.
- `src/life-record.js`: 제공된 인생 기록. 형의 미확인 항목은 null입니다.
- `src/data/chapter-plans.js`: 챕터 1–8의 설계. 2–8은 플레이 가능한 것으로 표시하지 않습니다.

대사는 `say(character,text,{sourceType,action})`, 묘사는 `narrate(text,...)`, 선택은 `choice(id,character,text,branches)`로 작성합니다. 일반 일상 대사의 기본 sourceType은 `fictional_dialogue`입니다. NPC 대사 함수가 저장된 `dialogueVisits`, `choices`, `storyScene`을 읽어 반응을 바꿉니다. 출처 설명을 대사 본문에 붙이지 마세요.

## 배포·오프라인

기본 배포 경로는 GitHub 프로젝트 Pages의 `/life-story-game/`입니다. `npm ci`, `npm run build`로 만든 `dist/`를 해당 경로에 서비스합니다. 사이트 루트에서 서비스할 경우에는 `VITE_BASE_PATH=/ npm run build`를 사용합니다.

**2026-11-04에 게임 사이트 공개와 소스 저장소 공개를 각각 승인받았습니다.** 현재 Public 저장소의 Pages Source는 GitHub Actions입니다. main push는 검증만 하며 실제 배포는 main에서 수동 요청합니다. `PUBLIC_SOURCE_APPROVED` 기록과 실제 공개 범위 검사, 공개 사이트 배포 동의를 모두 확인합니다. [Pages 설정과 승인 정책](docs/GITHUB_PAGES.md)을 참조하세요.

PWA scope/start_url도 프로젝트 경로를 사용합니다. 최초 온라인 리소스 캐싱 뒤에는 오프라인으로 이어할 수 있습니다. HTTPS 또는 localhost가 필요하며, 실제 Galaxy Chrome 설치는 별도 실기기 확인이 필요합니다.

기존 LocalStorage의 키와 스키마는 유지합니다. **새 사이트 주소(origin)는 기존 브라우저 저장을 자동으로 공유하지 않으므로, 기존 게임에서 JSON을 내보내고 새 주소에서 가져와야 합니다.** 배포 과정에서 기존 저장을 삭제하지 않습니다.

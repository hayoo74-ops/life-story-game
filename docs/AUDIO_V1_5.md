# v1.5 오디오 출처와 현재 품질

모든 효과음은 `src/audio.js`에서 직접 합성합니다. 외부 방송, 실제 TV 프로그램, 음성, 상용 효과음 또는 외부 녹음은 사용하지 않습니다. 별도 음원 라이선스 의무는 없습니다. 합성 로직은 프로젝트 소스와 함께 제공됩니다.

- TV: 전원 스위치의 짧은 대역 잡음, CRT의 낮은 작동 잡음, 말소리를 알아들을 수 없는 **합성 방송 질감**. 실제 사람이 말하는 한국어 방송은 이번 버전에 없습니다. 음성 방송 파일은 향후 직접 녹음하거나 상업적 사용 가능한 음원을 확보해야 합니다.
- 자동차: 이동 중에만 소리를 내는 필터 잡음. 실제 이동 속도로 재생 속도·필터·음량을 바꾸고, 시작·정지 때 플라스틱 접촉음을 냅니다. 전자 멜로디로 대체하지 않습니다.
- 문: 손잡이 클릭, 문 움직임, 닫힘의 저역 충격음. 시네마틱에서는 닫힘 애니메이션 완료에 맞춥니다.
- 실내: 낮은 실내 잡음과 시계 소리. 야외: 바람·먼 차량 질감·절제된 합성 새소리. 비: 실내에서 감쇠된 비, 문 밖의 고역 빗소리, 처마 물방울, 드문 낮은 천둥.
- 기억 획득 등 비현실적인 UI 알림에는 기존 음악적 효과를 유지합니다.

소리 기본값(음소거), 전체/음악/효과음 볼륨과 저장 방식은 유지합니다. 사용자의 클릭 뒤 AudioContext를 활성화합니다. 메뉴·백그라운드에서는 루프와 예약 효과를 정리하고 복귀 시 환경에 맞게 재시작합니다. 음악이 없는 작별 장면에서도 TV와 빗소리는 독립적으로 동작합니다.

합성음의 그래프/재생·정지·음량 연결은 자동 검증하지만, 실제 Galaxy 스피커에서의 청감과 녹음 수준의 사실성은 별도 실기기 평가가 필요합니다.

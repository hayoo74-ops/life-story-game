# LIFE STORY v1.3 — 탐색과 기억의 흔적

기준: v1.2.0 (`5de5428`). 기존 게임과 가족사의 순서를 보존하고 챕터 1의 놀이·조사·대화·보관 기능을 확장했습니다. 챕터 2–8은 계속 기획 단계입니다.

## 완료한 플레이 기능

- 이동에 가속·감속, 짧은 점프 입력 버퍼와 가장자리 유예를 적용했습니다. 월드 경계·바닥 충돌·위치 복구는 유지합니다. 놀이터의 낮은 상자는 충돌하며 걸어서 넘을 수 있습니다. 길 진행에 점프 실력을 요구하지 않습니다.
- 카메라가 이동 방향을 조금 앞서 바라봅니다. 기존 다층 배경에 창밖 구름·시계 바늘·잎·TV 화면 변화를 더했습니다. 환경 그래픽은 약 12.5Hz로 갱신하며, 움직임 줄이기 설정에서는 장식 움직임을 멈춥니다.
- TV는 전원과 화면·소리가 바뀌고 저장됩니다. 서랍은 열고 닫히며 조사 뒤 어머니의 반복 대사가 달라집니다. 장난감은 움직이고, 책에는 읽는 자세, 사진에는 확대, 침대에는 누운 자세와 페이드·방의 색 변화가 있습니다. 침대는 이야기의 연도나 가족 사건을 변경하지 않습니다.
- 공간 표지판 이동에 페이드·문 효과음을 추가했습니다. 실제 문의 경첩 애니메이션은 별도로 제작하지 않았습니다.
- 종이놀이: 비행기/배 선택 유지 → 세 번 접기 → 힘 선택 → 비행/밀기 → 거리별 형의 반응. 다시 할 수 있고 최고 거리·최근 거리·접기 진행을 저장합니다. ‘칸’은 게임상의 거리입니다.
- 액션가면: 아버지에게 다가간 뒤 세 자세 중 선택하고 몸짓을 보여 줍니다. 어머니의 반응과 재원 프레임이 달라집니다. 기존 22비트 연출과 두 실제 대사는 유지합니다.
- 공부: 세 문제를 풀고 답에 따른 반응을 읽습니다. 숫자 키 1/2/3으로도 고를 수 있습니다. 오답과 그림 보기 모두 같은 다음 장면으로 이어지며, 결과 때문에 가족사를 변경하지 않습니다.
- 선택·놀이 결과를 저장하고 형·어머니·할아버지의 후속 반응과 마지막 사진첩·앨범에 반영합니다. 가족사진·TV 조사와 형제 종이놀이를 마친 뒤 사진을 다시 보면 짧은 추가 회상이 열립니다.

## 대화와 접근성

- 글자 순차 출력: 느리게/보통/빠르게/즉시 표시. 터치·Enter는 먼저 전체 대사를 드러내고 다음 입력에서 넘깁니다.
- 기본/크게/아주 크게의 세 글자 크기, 고대비, 자막 배경, 움직임 줄이기.
- 대화 기록: 끝까지 표시한 최근 250개 대사. 읽은 대사 바로 보기와 자동 진행을 제공합니다. 자동 진행은 선택지를 고르거나 컷신을 넘기지 않습니다.
- 대화창의 Ⅱ·Esc로 일시정지합니다. 메뉴·기록·탭 비활성화 동안 글자와 자동 진행 타이머가 멈춥니다.
- Tab·Enter 및 숫자로 선택합니다. 선택지에서 Enter를 게임이 가로채던 문제와 메뉴의 방향키 입력 캡처를 수정했습니다.
- 기존 멀티터치와 화면 회전 대응을 유지합니다. 메뉴 포커스 범위에 슬라이더·체크박스·파일 선택도 포함했습니다.
- 조작키 재설정, 화면 읽기 프로그램을 위한 완전한 게임 월드 내비게이션은 미구현입니다.

## 오디오

외부 샘플 없이 Web Audio에서 직접 생성합니다. 따뜻한 어린 시절/학교/공부/단둘이의 시기/현재의 선율과 민감한 사건의 정적을 구분합니다. 실내·바람·비·TV 환경음, 시계·천둥·발걸음·종이·연필·서랍·문·장난감·기억 효과음이 있습니다.

전체·음악·효과음 음량과 음소거를 저장합니다. 대화 동안 배경을 낮추고 일시정지·음소거 시 노드·루프·예약 효과음을 정리합니다. 음성 연기는 없습니다. 실제 스피커의 청취 품질을 측정했다고 주장하지 않습니다.

## 저장 파일과 호환

현재 스키마는 **v4**입니다. v2/v3 진행·위치·기억·선택을 보존하고 새 필드의 기본값만 추가합니다. v1은 기존 정책대로 원본과 이전 수집을 보관하고 새 서사의 프롤로그에서 시작합니다. 이번 작업에서 새로 진행을 초기화하는 정책을 만들지 않았습니다.

- 원본 키: `life-story:save`
- 업그레이드 백업: `life-story:save:v1-backup`, `:v2-backup`, `:v3-backup`
- 수동 가져오기 직전 백업: `life-story:save:before-import` (최근 1회)
- 내보내기: 메뉴 → 저장 파일 → 현재 진행 내보내기.
- 가져오기: 파일 선택 → 장면·기억 수 확인 → 복구하기. 확인 전에는 진행을 쓰지 않습니다.
- JSON 문법·버전·필수 필드·장면/장소·크기(2MB)·내보내기 체크섬을 검사합니다. 원시 v1/v2/v3 JSON도 받습니다. 상위 버전, 미구현 챕터, 손상 파일, 백업/쓰기 실패는 기존 저장을 유지합니다.
- 체크섬은 우발적 손상 검사용이며 암호 서명이 아닙니다.
- 대화의 정확한 글자 위치·미니게임 비행 도중의 프레임은 저장하지 않습니다. 다시 열면 해당 장면의 자유 탐색부터 시작하고, 저장한 선택·접기/문제 진행을 다시 연결합니다.

## 사실과 창작

`real_memory`, `fictional_dialogue`, `dramatic_reconstruction`을 유지합니다. 새 문제·놀이 규칙·거리·자세 선택·일상 소품의 동작은 실제 사건을 추가하는 기록이 아닙니다. 게임의 선택 흔적은 재구성된 경험입니다. 일반 대화에 사실 확인 문구를 넣지 않고 앨범/출처 메모에서 설명합니다.

형은 기존의 날짜·거처 미지정 막간에만 등장합니다. 액션가면의 장난은 계속 화면 밖에서 표현하며 옷이나 신체를 노출하지 않습니다. 방문 사건의 원인·추가 폭력·새 목격자를 만들지 않습니다. 부모의 이혼을 선택으로 막거나 조부모 개별 체벌 행위자를 특정하지 않습니다.

## 아직 하지 않은 작업

- 챕터 2–8의 실제 플레이 콘텐츠. 자료가 부족한 내용을 완성한 사실처럼 만들지 않았습니다.
- 후속 챕터의 고유 업무·기사 작성·여행 미니게임과 전용 이벤트 연출. 등록 구조와 저장 필드는 준비했으며 실제 연결은 콘텐츠 작성 시 필요합니다.
- 전문 작곡·녹음·성우, 실제 사진을 이용한 외형, 키 재설정.
- Galaxy S24 Ultra·삼성 인터넷·iOS Safari 실기기 검증, 실제 스피커 평가, 장기간 캐시 보존 시험.
- 공개 게임 호스팅. GitHub 소스 업로드와 별개이며 접속 URL을 임의로 만들지 않습니다.

실행과 배포는 README, 측정 결과와 검사 한계는 VALIDATION, 확장 절차는 CHAPTER_EXTENSION을 참조하세요.

진단 표본은 자유 탐색 중 최근 최대 1,200프레임이며, 0ms 이하/1초 이상 간격은 제외합니다. 이 간이 진단은 긴 정지까지 모두 포함하는 전문 성능 추적기가 아닙니다.

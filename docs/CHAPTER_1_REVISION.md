# 챕터 1 최신 기록 반영

2026-11-03, v1.1. 원본 프로젝트를 초기화하지 않고 기존 엔진·픽셀아트·조작·PWA를 확장했습니다. Git 이력의 v1은 그대로 보존합니다.

## 우선하는 사실 순서

1. 1997-01-26 부산 출생.
2. 부산 사하구 학장동에서 아버지·어머니와 생활.
3. 종이가면을 쓰고 부모님 앞에서 액션가면 포즈. 두 직접 대사와 아버지의 장난, 가족이 웃은 기억.
4. 약 1~2년 뒤 아버지가 어머니가 있는 방문을 발로 차서 파손. 어린 재원이 현장에서 직접 목격.
5. 얼마 후 부모님 이혼. 단일한 원인으로 연결하지 않음.
6. 아버지와 약 1~2년 단독 동거. 구체적인 사건·분위기·대화는 미확인.
7. 이후 부산 남구 대연동 조부모님 댁으로 거처 이동. 이유·과정은 미확인.
8. 공부에 매우 엄격한 양육, 많은 공부, 여러 문제를 틀리면 심한 꾸중, 회초리 체벌을 받기도 함. 횟수·욕설·상해·개별 역할은 미확인.

학장동의 행정구 표기는 최신 사용자 기록을 따릅니다. 이를 근거로 실제 주거지나 당시 주소를 추론하지 않습니다. 유년기의 연도와 나이를 임의로 지정하지 않았습니다.

## 장면과 인물

프롤로그와 본편 장면 01–12는 README의 표를 따릅니다. 주요 사건 12개는 `EVENT_RECORDS`에 출처 분류가 있습니다. 어린/현재 재원은 플레이어이며 NPC와 구별합니다.

실제 가족 NPC는 **아버지·어머니·할머니·할아버지**입니다. 창작 배경 인물은 **골목의 이웃·동네 아이·문구점 주인·대연동의 이웃**입니다. 8종의 인물을 11개 NPC 배치로 표현합니다. 가족의 일반 상호작용은 실제 직접 대사가 아닌 ‘기록’ 서술로 표시합니다.

학장동 집과 같은 집의 시간별 상태, 아버지와 살던 기간의 상징적 공간, 대연동 거리와 공부방, 현재의 방·거리, 기존 선택 탐험 4개 맵으로 구성합니다. 정확한 집의 구조와 동선·가구를 재현한 것이 아닙니다.

## 사물·선택

조사 데이터 28종: 가족사진, TV, 장난감, 소파, 신발장, 창문, 종이가면, 닫힌 방문, 시간 책갈피, 부서진 방문, 가족 변화 기록, 두 사람의 의자, 단독 동거 기간 기록, 빈 노트, 대연동 기록, 공부책상, 문제집, 공부방 연필, 지우개, 시계, 책장, 회초리, 공부 마무리 기록, 현재 사진첩, 가로등, 그네, 문구점 연필, 학교 가방.

공부 마무리와 현재 사진첩은 이벤트 오브젝트로 사용합니다. 나머지는 조사와 선택 대화로 연결됩니다. 28개 정의가 모두 독립적인 실제 소유 물품을 의미하지 않습니다. 배치된 조사 사물 26종의 관점 선택과 공부의 3분기 선택을 데이터화했습니다. 선택은 현재 플레이어가 어떤 설명을 읽을지 정하며, 어린 재원의 실제 심리로 저장하지 않습니다.

기억 16종: 함께 살던 학장동 집, 액션가면, 상대 시간 책갈피, 방문 직접 목격, 달라진 가족 구성, 아버지와의 기간, 대연동 거처, 공부 중심 생활, 회초리, TV, 창작 장난감, 가로등, 그네, 문구점 연필, 공부책상, 현재의 정리 앨범. 각 기억의 실제/재구성/창작 표식은 데이터와 앨범에 함께 표시합니다.

## 전용 회상

- 가면: 독창적인 별 무늬 마스크가 얼굴로 내려오는 착용 연출, 영웅 자세, TV 옆 부모, 밝은 웃음 글자와 합성 효과음, 따뜻한 광원. 바지 장난은 서술과 화면 밖 처리만 사용하고 속옷·신체 노출은 없음.
- 방문: 같은 집의 차가운 색감, 어린아이의 낮은 시점, 아버지의 발차기 동작, 문 균열·파편, 짧은 충격음, 배경음 정지. 인물의 추가 폭력·상해와 당시 말·감정을 추가하지 않음.
- 공부: 예시 문항은 창작 표시. 정답·오답·건너뛰기 어느 것도 처벌을 일으키지 않음. 체벌은 실제 기록과 상징적 회초리만 사용하며 정당화하지 않음.

## 저장과 분량

v1의 원본 백업 및 `legacyArchive` 보존, v2의 장면/선택/조사/이벤트/기억 연동은 README의 마이그레이션 절차를 따릅니다. 사라진 옛 진행 ID가 새 이야기의 순서를 건너뛰게 하지 않습니다.

분량은 선택 조사를 읽는 20–30분 목표입니다. 사물 대사의 한 분기만 각각 읽어도 약 4,100자이며, 여기에 가족 기록·회상·사진첩 정리를 더합니다. 읽기 속도 400–550자/분을 가정한 추정과 이동·조사 시간을 조합했으며, 사람의 실제 플레이를 측정한 결과는 아닙니다. 자동화 완료 시간은 사람이 느끼는 플레이 시간으로 사용하지 않습니다. 추가 생활 기록 없이 강제 대기나 반복을 넣지 않습니다.
